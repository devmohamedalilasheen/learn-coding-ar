📚 الفهرس

1 يعني إيه JavaScript؟ 🤔

نرجع لمثال البيت 🏠:

  • HTML = الطوب والحيطان.
  • CSS = الدهان والديكور.
  • JavaScript = الكهربا ⚡. لما تدوس على زرار النور، النور ينوّر. لما ترن الجرس، الجرس يضرب.

يعني JavaScript (واختصارها JS) هي اللي بتخلّي الصفحة تفكّر وتتصرف: لما تدوس زرار يحصل حاجة، لما تكتب غلط يطلعلك تحذير، لما تضيف حاجة للسلة العدد يزيد.

والأهم: JS دي لغة برمجة بجد. يعني إنت بتدّي الكمبيوتر أوامر وهو ينفذها بالترتيب، زي وصفة الأكل بالظبط 🍳: «حط الزيت، استنى يسخن، حط البيض...».

💡 متخافش من الكود دهلسه مش مطلوب منك تفهمه. في آخر الصفحة هتلاقي نفسك فاهمه كله 😉. بس دوس على الزرار اللي في «📺 الشاشة».

2 الكونسول: أول أمر ليك 🖥️

الكونسول (Console) ده زي كشكول ملاحظات الكمبيوتر بيكتب لك فيه. أهم أمر في الدنيا:

console.log("أهلًا");
🖥️ console = الكشكول ✍️ log = اكتب فيه 💬 اللي بين القوسين = تكتب إيه

دوس ▶️ شغّل وشوف الكلام بيطلع في «🖥️ الكونسول»:

⚠️ لاحظالكلام العادي لازم يبقى بين علامتين تنصيص "...". لكن الأرقام والحسابات من غير تنصيص. وفي آخر كل أمر ; (زي النقطة في آخر الجملة).

فين بتكتب JS في الحقيقة؟

جوه ملف HTML، في وسم <script> قبل ما تقفل الـ body:

<body>
  <h1>صفحتي</h1>

  <script>
    console.log("أهلًا");
  </script>
</body>

وعشان تشوف الكونسول الحقيقي في أي موقع: دوس F12 واختار Console. 🔍

💡 التعليقاتأي سطر بيبدأ بـ // ده ملاحظة ليك، الكمبيوتر بيتجاهله خالص.

3 المتغيرات: علب بتشيل حاجات 📦

المتغير (Variable) = علبة عليها اسم وجواها حاجة. زي علب المطبخ: علبة مكتوب عليها «سكر» وجواها سكر.

let age = 25;
🆕 let = «اعمل علبة جديدة» 🏷️ age = اسم العلبة = معناها «حط جواها» 🎁 25 = اللي جواها

let ولا const؟

  • let = علبة عادية 📦 تقدر تغيّر اللي جواها براحتك.
  • const = علبة مقفولة بقفل 🔒 تحط فيها حاجة مرة واحدة وخلاص، متتغيرش (زي تاريخ ميلادك).
🎮 لعبة: رفّ العلب اعمل علب

اعمل علبة: اختار نوعها، اكتب اسمها (بالإنجليزي) وحط جواها حاجة. وبعدين جرّب تغيّر اللي جوه علبة const وشوف هيحصل إيه 😈

8 اللوب (Loop): كرّر من غير ما تزهق 🔁

لو عايز تكتب «أنا شاطر» 100 مرة، هتكتب 100 سطر؟ لأ طبعًا 😅. اللوب بيقول للكمبيوتر «كرّر الكلام ده كذا مرة».

for (let i = 1; i <= 5; i++) { ... }
🏁 ابدأ العدّ من 1 ❓ طول ما i أصغر من أو يساوي 5 كمّل ➕ كل لفة زوّد i واحد
🎮 لعبة: وصّل الروبوت للنجمة 🤖⭐ النجوم: 0

الروبوت بيمشي خطوة واحدة كل لفة. كام لفة محتاج عشان يوصل للنجمة بالظبط؟ (لو زوّدت هيعدّيها 😅)

🎮 لعبة: العدّاد غيّر الأرقام
for (let i = ; i < ; i += )

while: كرّر طول ما...

while بيقول «طول ما الشرط صح، كمّل». زي «طول ما إنت جعان كُل لقمة» 🍔.

⚠️ اللوب اللي مبيخلصشلو نسيت تقلّل hunger، الشرط هيفضل صح على طول والصفحة هتهنّج 🥶. دايمًا اتأكد إن اللوب ليه نهاية.

  • function = «هعمل مكنة».
  • sayHello = اسم المكنة.

12 إزاي JS يمسك حاجة في الصفحة ويغيّرها؟ ✋

الصفحة بالنسبة لـ JS عبارة عن شجرة عناصر اسمها DOM. وعشان تغيّر حاجة لازم الأول «تمسكها»:

  1. حط على العنصر id في الـ HTML: <p id="msg">
  2. امسكه في JS: document.getElementById("msg")
  3. غيّر فيه: الكلام بـ .textContent، الشكل بـ .style
الأمربيعمل إيه
document.getElementById("x")هات العنصر اللي الـ id بتاعه x
document.querySelector(".card")هات أول عنصر يطابق محدِّد CSS (زي اللي اتعلمناه في CSS)
el.textContent = "..."غيّر الكلام اللي جواه
el.style.color = "red"غيّر الـ CSS بتاعه (الاسم بيتكتب fontSize مش font-size)
el.classList.add("x")زوّد عليه كلاس
input.valueاقرا اللي المستخدم كتبه في خانة

الـ Event = حاجة بتحصل في الصفحة: المستخدم داس، كتب، حرّك الماوس. وإحنا بنقول لـ JS: «استنى الحدث ده، ولما يحصل نفّذ الكلام ده».

الحدثبيحصل إمتى
clickلما يدوس على العنصر

mouseoverلما الماوس يدخل على العنصر

submitلما يبعت فورم

17 الأخطاء: صحابك الجداد 🐞

كل المبرمجين بيغلطوا كل يوم، عادي جدًا. المهم تعرف تقرا الغلطة. الصفحة دي بتترجملك الأخطاء بالمصري لما تشغّل كود فيه مشكلة. جرّب:

الغلطةيعني إيه بالمصري
x is not definedبتستخدم علبة اسمها x مش موجودة. غالبًا كاتب الاسم غلط أو نسيت let.
Unexpected tokenفيه حرف في غير مكانه: قوس ناقص، أو زيادة، أو تنصيص مقفلتوش.
is not a functionبتشغّل حاجة على إنها مكنة وهي مش مكنة. اتأكد من الاسم.
Assignment to constantبتحاول تغيّر علبة const المقفولة.
Cannot read properties of nullبتمسك عنصر مش موجود في الصفحة. اتأكد من الـ id.

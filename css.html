🎨 تعلّم CSS من الصفر... وإنت بتلعب!

الصفحة دي معمولة لأي حد مالوش أي علاقة بالبرمجة خالص. هنشرح كل حاجة بالراحة وبأمثلة من الحياة. وفي كل درس فيه 🎮 لعبة تحرّك فيها حاجات وتشوف إيه اللي بيحصل بعينك، من غير ما تحفظ حاجة.

📚 الفهرس

1 يعني إيه CSS؟ 🤔

فاكر لما قلنا إن الموقع زي البيت؟

  • HTML = الطوب والحيطان 🧱 (فيه عنوان، فيه كلام، فيه زرار).
  • CSS = الدهان والديكور والعفش 🎨 (لون الحيطة إيه؟ الكنبة فين؟ الإضاءة شكلها إيه؟).

يعني CSS مبتضيفش حاجات جديدة للصفحة، هي بس بتحلّي الحاجات الموجودة: تلوّنها، تكبّرها، تحركها، ترتبها جنب بعض.

اسمها اختصار لـ Cascading Style Sheets، يعني تقريبًا «ورقة التنسيقات». متشغلش بالك بالاسم 😄.

🎮 جرّب: شيل الـ CSS وشوف المصيبة دوس على الزرار

دي نفس الصفحة بالظبط، نفس الـ HTML. الفرق الوحيد إن فيه CSS أو مفيش.

✨ دلوقتي الصفحة بالـ CSS: حلوة ومتظبطة.
💡 خليك فاكرHTML بيقول «فيه إيه في الصفحة». CSS بيقول «الحاجات دي شكلها عامل إزاي».

«يا أسطى، العناوين ← خلّي لونها ← أحمر»

3 المحدِّدات (Selectors): لوّن مين؟ 🎯

قبل ما تلوّن أي حاجة، لازم تقول لـ CSS: «أنا عايز ألوّن مين بالظبط؟». الكلمة اللي بتكتبها في الأول دي اسمها Selector (يعني «المحدِّد» أو «اللي بيختار»).

تخيّل إنك في فرح 🎉 وعايز تنادي على ناس. عندك 3 طرق بس:

1️⃣ تنادي بالنوع: «يا كل الستات!» في HTML كل حاجة ليها نوع: h1 = عنوان، p = فقرة، li = سطر في قايمة.
في CSS تكتب النوع زي ما هو:
p { color: red; } ← معناها: «كل الفقرات في الصفحة تبقى حمرا».
2️⃣ تنادي بالتيشيرت: «اللي لابس تيشيرت أحمر!» (ده اسمه class) في HTML ممكن تلبّس أي حاجة «تيشيرت» عليه اسم، كده: <p class="red">
ناس كتير ممكن يلبسوا نفس التيشيرت.
في CSS تكتب نقطة . وبعدها اسم التيشيرت:
.red { color: red; } ← معناها: «أي حد لابس تيشيرت red يتلوّن».
3️⃣ تنادي بالاسم: «يا أحمد!» (ده اسمه id) الـ id ده زي اسم الشخص، مينفعش اتنين يبقى ليهم نفس الـ id. في HTML: <ul id="menu">
في CSS تكتب شباك # وبعدها الاسم:
#menu { color: red; } ← معناها: «الحاجة اللي اسمها menu بس».
🧠 احفظ دي بس من غير علامة = نوع (p)  |  نقطة . = class (.red)  |  شباك # = id (#menu)

إزاي تلعب؟

  1. بص على الكلمة اللي في المربع الأسود 👇 (ده المحدِّد).
  2. اقرا معناها بالعربي اللي تحتها.
  3. تحت فيه صفحة صغيرة فيها صناديق. فوق كل صندوق مكتوب: نوعه و التيشيرت (class) و اسمه (id).
  4. دوس على كل صندوق إنت شايف إنه هيتلوّن (هيبقى أصفر 🟨). ولو غلطت دوس عليه تاني يرجع.
  5. دوس ✅ اتأكد.

4 الألوان 🌈

فيه خاصيتين هتستخدمهم طول الوقت:

  • color = لون الكلام نفسه.
  • background-color = لون الخلفية (اللي ورا الكلام).

وتقدر تكتب اللون بأكتر من طريقة:

الطريقةشرحها
red, blue, goldباسمه بالإنجليزي. سهل جدًا، وفيه أكتر من 140 اسم.
rgb(255, 0, 0)خليط من أحمر، أخضر، أزرق. كل واحد من 0 لـ 255. (العب باللعبة اللي تحت وهتفهم)
#ff0000نفس الـ rgb بس مكتوب بشكل مختصر (Hex). المصممين بيحبوه.
rgba(0,0,0,0.5)زي rgb + رقم رابع للشفافية من 0 (شفاف خالص) لـ 1 (مش شفاف).
🎮 لعبة: خلّاط الألوان النقط: 0

الشاشة بتعمل كل الألوان من 3 لمبات بس: 🔴 أحمر و🟢 أخضر و🔵 أزرق. كل لمبة من 0 (مطفية) لـ 255 (منوّرة على الآخر). حرّك الأشرطة لحد ما لونك يبقى شبه اللون المطلوب.

6 الخلفيات 🖼️

الخلفية ممكن تكون لون واحد، أو تدرّج (لون بيتحول للون تاني بالراحة)، أو صورة.

ولو عايز صورة: background-image: url("photo.jpg"); ومعاها background-size: cover; عشان الصورة تغطي المكان كله من غير ما تتمط.

7 سر الصندوق 📦 (Box Model) - أهم درس!

اسمع الحتة دي كويس: أي حاجة في الصفحة عبارة عن صندوق. العنوان صندوق، الصورة صندوق، الزرار صندوق.

وكل صندوق زي برواز الصورة اللي على الحيطة 🖼️:

  • 🔵 Content (المحتوى): الصورة نفسها، أو الكلام.
  • 🟢 Padding (الحشو): المسافة الفاضية جوه البرواز بين الصورة والإطار (الكرتونة البيضا).
  • ⬛ Border (الإطار): البرواز الخشب نفسه.
  • 🟠 Margin (الهامش): المسافة برّه البرواز بينه وبين أي برواز تاني على الحيطة.
🎮 لعبة: ابني الصندوق حرّك الأشرطة

8 الإطار، الحواف المدورة، الظل 🔵

  • border: 3px solid red; = إطار (تخانته، نوعه، لونه). الأنواع: solid متصل، dashed شرط، dotted نقط.
  • border-radius = تدوير الزوايا. ولو خليته 50% المربع يبقى دايرة!
  • box-shadow = ظل الصندوق.
  • transform: rotate(45deg) = لفّ العنصر. وscale(1.5) = كبّره.

11 Flexbox: إزاي ترصّ الحاجات جنب بعض 🧲

Flexbox ده أشهر وأسهل طريقة ترتّب بيها الحاجات. الفكرة: عندك صندوق أب (زي الرف 📚) وجواه عيال (الكتب). إنت بتكلم الأب وتقوله يرصّ عياله إزاي.

أول حاجة: تقول للأب display: flex; ← العيال يقفوا جنب بعض على طول.

الخاصية (على الأب)بتعمل إيه
justify-contentبترتّب العيال على الخط الرئيسي (العرضي في العادي ↔️): flex-start البداية، center النص، flex-end الآخر، space-between فرّقهم على الأطراف، space-around مسافات حواليهم
align-itemsبترتّبهم على الخط التاني (الطولي في العادي ↕️): flex-start فوق، center النص، flex-end تحت
flex-directionاتجاه الرصّ: row صف (عادي)، column عمود، وrow-reverse صف بالمقلوب
gapمسافة ثابتة بين العيال
🎮 لعبة: ركّن العربيات 🚗 مستوى 1 من 8

ملحوظة: الجراج ده بيتقري من الشمال لليمين زي الإنجليزي، فـ flex-start = الشمال، وflex-end = اليمين.

💡 أشهر استخدام في الدنياعشان تحط أي حاجة في النص بالظبط (أفقي ورأسي): display:flex; justify-content:center; align-items:center; احفظها 😉

12 Grid: قسّم الصفحة لمربعات زي الشطرنج ♟️

لو Flexbox بيرصّ في صف واحد، فالـ Grid بيقسّم المكان لـ صفوف وأعمدة مع بعض، زي كراتين البيض 🥚.

  • display: grid; = شغّل الشبكة.
  • grid-template-columns: 1fr 1fr 1fr; = 3 أعمدة متساوية. (fr = «حتة» من المكان الفاضي)
  • أو اختصار: repeat(3, 1fr) = كرّر «1fr» 3 مرات.
  • gap = المسافة بين المربعات.

14 لما الماوس يعدّي (hover) والحركة الناعمة ✨

:hover معناها «لما الماوس يقف على العنصر». وبيتكتب بعد اسم المحدِّد كده: button:hover { ... }

وtransition بتخلّي التغيير يحصل بالراحة بدل ما يحصل فجأة.

✨ جرّبعدّل في المثال وغيّر 0.4s لـ 2s (بطيئة جدًا) أو امسح سطر الـ transition خالص وشوف الفرق.

16 الموقع على الموبايل 📱 (Responsive)

الموقع لازم يبان حلو على الكمبيوتر الكبير وعلى الموبايل الصغير. عشان كده بنستخدم @media اللي معناها: «لو الشاشة صغيرة، طبّق الكلام ده».

@media (max-width: 600px) {
  /* الكلام هنا بيشتغل بس لو الشاشة أصغر من 600 */
  .boxes { flex-direction: column; }
}
🎮 لعبة: صغّر الشاشة اسحب الشريط
⚠️ متنساشعشان الموبايل يفهم الكلام ده لازم تحط في الـ head: <meta name="viewport" content="width=device-width, initial-scale=1.0">
